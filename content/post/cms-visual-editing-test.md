> 这是一篇**测试文章**，用来验证博客的可视化编辑后台（Decap CMS）能不能正常走通"写文章 → 保存 → 自动部署上线"的完整流程。你可以放心在这篇文章上练习，练完在后台把它删掉即可。

## 这篇文章想验证什么

1. **后台能正常登录**（GitHub 授权）
2. **新建文章并保存**后，能自动推送到仓库
3. **GitHub Actions 自动构建部署**，线上 URL 正常访问
4. **Markdown 渲染**正常：标题、列表、引用、代码块、表格、图片

## Markdown 功能演示

### 无序列表

- 支持中文内容
- 支持 **加粗**、*斜体*、`行内代码`
- 支持图片上传（存到 `/img/`）

### 有序列表

1. 打开 https://gavin1668.github.io/admin/
2. 点击 **Login with GitHub** 授权
3. 进入后台 → 文章 → 新建文章
4. 写好后点保存，等待部署即可

### 代码块

```bash
# 手动发布文章（后台保存后会自动执行，无需手动操作）
git add content/post/xxx.md
git commit -m "新增文章"
git push origin main
```

### 引用

> 后台的本质：把你在编辑器里写的 Markdown 自动提交到 GitHub 仓库，再由 GitHub Actions 构建部署——你只负责写，剩下的自动化。

### 表格

| 能力 | 说明 |
|---|---|
| 新建文章 | 后台直接创建，自动生成 front matter |
| 编辑旧文 | 列表点击即可改，改完保存 |
| 图片管理 | 上传到 `static/img/`，用 `/img/...` 引用 |
| 草稿 | `draft: true` 不会上线，发布时才设 false |

## 测试结论

如果这篇文章能正常显示以上所有元素，说明**可视化后台 → 仓库 → 自动部署**整条链路完全打通。接下来就可以开始用后台写真正的文章了。
